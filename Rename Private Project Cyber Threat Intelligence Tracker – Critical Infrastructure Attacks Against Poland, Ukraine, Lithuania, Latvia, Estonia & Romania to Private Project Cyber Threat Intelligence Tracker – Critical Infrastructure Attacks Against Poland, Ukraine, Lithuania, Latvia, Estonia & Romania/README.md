# Cyber Threat & Disinformation Tracker — Eastern Europe

Own research project tracking cyberattacks against critical infrastructure and related information operations across Eastern Europe.

## 🎯 Scope

Countries monitored:
- 🇵🇱 Poland
- 🇺🇦 Ukraine
- 🇱🇹 Lithuania
- 🇱🇻 Latvia
- 🇪🇪 Estonia
- 🇷🇴 Romania

## 📋 What this project does

- **OSINT collection** — ongoing gathering of data from multiple open sources on cyberattacks targeting critical infrastructure in the countries above (threat actors, malware families, targeted sectors, dates, affiliations).
- **Structured data tracking** — all findings are logged and maintained in Excel as the primary data source.
- **Power BI dashboards** — data is transformed and modeled in Power BI to produce statistics, trend charts, and interactive dashboards, including:
  - Threat actor timelines (active since / by year)
  - Attack types and targeted sectors
  - Regional breakdowns
  - Filterable, interactive views for exploring the dataset
- **Information space analysis** — parallel monitoring of hostile narratives and disinformation activity connected to the same threat landscape, with particular attention to Lithuania and Poland as frequently targeted countries.
- **Correlation** — the end goal is to connect technical attack data with influence operations, building a fuller picture of regional threat exposure rather than treating cyber and information threats as separate domains.

## 🛠️ Tools used

| Tool | Purpose |
|---|---|
| Excel | Primary data collection and structuring |
| Power BI | Data modeling, statistics, dashboards, and visualizations |
| OSINT sources | Public reporting, security vendor research, government advisories (e.g. CERT-UA), news media |

## 📊 Example outputs

- Threat actor tables (ID, type, affiliation, region, active since)
- Bar/line charts showing when threat groups became active
- Dashboards filterable by year/time range
- Narrative tracking notes on disinformation trends by country
